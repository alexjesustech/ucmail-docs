# Guia Rápido

1. Instale o UCMail pela loja de extensões do navegador (ou carregue o build de desenvolvimento).
2. Abra o Gmail. O controle do UCMail aparece junto à barra de abas nativa.
3. **Pilar 1:** ative "Ocultar lidas" em qualquer aba (Principal, Promoções, Social, Atualizações, Fóruns).
4. **Pilar 2:** abra *Varredura de inscrições* no popup para descadastrar em lote com atrasos seguros.
5. **Pilar 3:** selecione uma mensagem → *Exportar para Markdown* → o ficheiro chega aos downloads com cabeçalho de metadados.
