# Quick Start

> Canonical page — translations mirror this file.

1. Install UCMail from your browser's extension store (or load the dev build).
2. Open Gmail. The UCMail toggle appears next to the native tab bar.
3. **Pillar 1:** toggle "Hide read" on any tab (Primary, Promotions, Social, Updates, Forums).
4. **Pillar 2:** open *Subscriptions sweep* in the popup to batch-unsubscribe with safe delays.
5. **Pillar 3:** select a message → *Export to Markdown* → file lands in your downloads with a metadata header.
